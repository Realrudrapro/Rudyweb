# Contributing to RUDYweb

Thank you for wanting to contribute to RUDYweb! 🎉

RUDYweb is a community-driven project, and contributions from everyone are welcome. Whether you're fixing a small bug, improving the design, adding a game, or suggesting a new feature, your contribution can help make RUDYweb better.

## How to Contribute

### 1. Fork the repository

Create your own fork of the RUDYweb repository on GitHub.

### 2. Create a branch

Create a new branch for your changes.

```bash
git checkout -b my-change
```

Try to give your branch a descriptive name, such as:

```text
feature/new-game
fix/mobile-navigation
improvement/news-page
```

### 3. Make your changes

Make your changes and test them before submitting them.

Please try to keep your changes focused. If you're fixing one bug, avoid making unrelated changes at the same time.

### 4. Commit your changes

Write a clear commit message explaining what you changed.

```bash
git add .
git commit -m "Add new game"
```

### 5. Push your branch

```bash
git push origin my-change
```

### 6. Open a Pull Request

Open a Pull Request on GitHub and explain:

* What you changed
* Why you changed it
* Anything that should be tested
* Any relevant issues

Please be patient while your Pull Request is reviewed. Changes may be requested before it is merged.

## Reporting Bugs

Found a bug? Open a GitHub Issue.

Please include:

* What happened
* What you expected to happen
* Steps to reproduce the problem
* Your browser and device, if relevant
* Screenshots or other useful information, if available

## Suggesting Features

Have an idea for RUDYweb?

Open a GitHub Issue and describe:

* What you want to add
* Why it would be useful
* How you think it could work

Not every suggestion will be implemented, but every idea is welcome.

## Code Guidelines

Please keep code:

* Easy to understand
* Consistent with the existing project
* Organized
* Free of unnecessary changes

For JavaScript, HTML, and CSS, try to follow the style already used in the project.

Do not intentionally add malicious, harmful, or insecure code.

## Games and Other Content

New games and features are welcome!

Before contributing content, make sure you have the right to use any images, sounds, fonts, code, or other assets that you add.

Do not submit copyrighted material that you do not have permission to use.

## Pull Request Guidelines

Pull Requests should:

* Have a clear title
* Explain the changes
* Be tested before submission
* Follow the project's existing structure
* Avoid unrelated changes

Pull Requests may be modified, rejected, or closed if they do not fit the direction of RUDYweb.

## Community

Please be respectful to other contributors.

Different opinions and approaches are normal in an open-source community. Discuss ideas respectfully and focus on improving the project.

For more information, see our [Code of Conduct](CODE_OF_CONDUCT.md).

## Thank You!

Every contribution matters.

Whether you submit code, report a bug, suggest an idea, improve documentation, or simply help another contributor, thank you for helping build RUDYweb. ❤️
